# VEDA audit — 24 Oct 2026 — incremental 44f33b0..0f12eaa (127 commits)

Profile: web app + API (FastAPI, Python 3.13) · multi-agent flood-risk advice · data: public river/rain data, optional free-text feedback (no accounts) · exposure: **public internet** (offline demo via Tailscale Funnel on the Wyse) + local live mode · deploy: docker compose on one home server, solo operator.
Dimensions run: 1 Functional, 2 Security, 3 Data integrity, 6 Reliability, 7 Accessibility/UX, 8 Code quality, 9 Deploy/ops.
Skipped: 4 Compliance (no personal data collected; feedback form asks visitors not to write personal details — unchanged since 23 Oct), 5 Performance (one run ≈ 0.08 s in demo; one run at a time).
Method: clone of HEAD 0f12eaa in Cowork's sandbox; full test suite; TestClient + real uvicorn with VEDA_DEMO=1; throwaway repro scripts; live demo inspected at 375 px in a browser.

**Verdict: GO for the demo once the four P1s below are fixed.** No P0.

## High (P1)
1. **[Dim 2] Anyone can freeze the public demo by holding ~40 `/live/stream` connections open.** `app/main.py:364-385` uses a sync generator; each watcher blocks one of the 40 threadpool threads in `q.get(timeout=15)`; heartbeats keep it alive forever; no watcher cap; nginx gives `/live/stream` burst 60 nodelay and no `limit_conn`. Repro (uvicorn, VEDA_DEMO=1, 45 sockets): `/health` timed out 10.03 s, `/ui/words` 10.01 s. With 30 sockets all OK. Fix: async generator (asyncio.Queue per watcher), cap ~20 watchers (503 above), `async def health`; nginx `limit_conn` 3 per visitor on `/live/stream` and `/run/stream`, `worker_connections 1024`.
2. **[Dim 1 / safety] Stale "rain upstream" fact is reused as current, with no age.** `veda_ingest.py:398-401` returns None on a failed/skipped hourly-rain query (optional query; also skipped while the `open_meteo` breaker is open, `data_agent.py:72,585`) without retracting the old fact; `context.py:37-39` returns newest fact whatever its age; `gather` gives no freshness to `rain_upstream` (`data_agent.py:936-958`); `forecast_agent.py:351-365` keeps raising the verdict. Repro: upstream-rain scene then calm scene with the rain query forced to None → still PREPARE, card quotes Nov rain totals. Live mode only (world.sqlite persists). Fix: age-check `rain_upstream` against the clock; when stale or not read this run → None + "not checked"; test.
3. **[Dim 1 / safety] Trapped person gets no stranded advice when Zetaris is down.** `loop.py:124-136` (ZetarisError branch) answers `unavailable_reply` without the `router.emergency()` check that the place-not-found branch has (`loop.py:144-149`). Repro: "I am trapped, water in my house at Tumpat" → only "VEDA cannot reach its river data right now…". Same for the deadline answer (`loop.py:110-116`), which is also English-only. Fix: wrap both with `card.emergency_reply(lang, …)` when `router.emergency(question)` matches; deadline text in EN + BM; tests + an eval.
4. **[Dim 8] A clean Linux clone fails one test.** `scripts/make_synthetic_scenes.py:188-190` picks the clock fixture with `next(... FIXTURES.glob("*.json") if "current_timestamp()" in ...)`; three fixtures contain that string and glob order is filesystem-dependent. In a fresh clone on Linux it picks `65493dd742855899.json` → `ValueError: Invalid isoformat string: '0'`; `tests/test_no_jps_readings.py::test_synthetic_values_are_exactly_what_the_seeded_method_makes` fails (903 pass, 1 fail). CI passes by directory-order luck. Judges cloning on Linux would see a red test. Fix: select the fixture whose SQL is exactly `SELECT current_timestamp() AS now_utc` (and `sorted()` the glob).

## Medium (P2)
5. **[Dim 2] Feedback box can be filled by one person in about an hour.** `demo/feedback/feedback.py:153-155` keeps control characters (stored as 6-byte `\uXXXX`), ~15 KB per record → 20 MB cap (`:28`) after ~1,400 posts; no Origin/Sec-Fetch-Site check on POST. Fix: strip `\x00-\x1f\x7f`, cap a record at ~3 KB, reject cross-site posts, raise the cap or rotate.
6. **[Dim 2] CSV export open to spreadsheet formula injection.** `feedback.py:190-200`; `=HYPERLINK(...)` came out unchanged. Fix: prefix `'` on values starting `= + - @ \t \r`.
7. **[Dim 6] Slow empty model reply not retried.** An empty HTTP-200 stream raises "did not return valid JSON" (`nightshift.py:306-310`); `is_empty_response` is False for it (`:136-140`) and the draft retries only failures under 10 s (`coordinator.py:190-196`). Fix: raise an "empty response" error when the text is empty.
8. **[Dim 7] Public demo UX** — see the design critique (24 Oct): default scene lands on "Can't confirm"; no context; banner takes a third of the screen; scene picker hidden; jargon on the card.
