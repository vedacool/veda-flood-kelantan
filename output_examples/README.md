# Output examples (B-20)

The **real, unedited** answers VEDA gave to `input_examples/`, generated by `python scripts/make_examples.py` (nothing hand-written; re-run it to regenerate). Each example has the API's JSON answer (`NN_name.json`) and its full trace (`NN_name.trace.jsonl` - every agent step, Zetaris query and decision).

**Mode:** these were produced in **SAMPLE_MODE** (offline) on **scenes** - the Nov 2024 replay (readings reported in the news, each cited) or a **SYNTHETIC** scene (made-up readings, labelled SYNTHETIC on the card and in the trace). No JPS readings are stored in this repo (B-75), so Nemotron is not called: the answer is the code-written card and the Critic reviews with code + Zetaris checks (marked `fallback` in the trace). `python scripts/make_examples.py --live` produces live ones, which add the AI explanation and the AI Critic's review.

VEDA never reads this folder at runtime (guard test in `tests/test_architecture.py`).
